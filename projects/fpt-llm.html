Internship Project — 2025–2026

FPT-LLM

A self-hosted AI research assistant built for local FPT Software employees, enabling document Q&A, cited answers, summaries, and summary-slide PDF generation.

Role
Software Engineering Intern
Stack
Next.js, FastAPI, SurrealDB, Ollama, Docker
Timeline
Oct 2025 – Jul 2026
View Code ↗

This is a personal copy of a project originally developed during my internship at FPT Software. The original repository is privately maintained by the organisation and is shared here for portfolio purposes only.

The assistant gives local employees a way to ask questions directly against internal documents and get cited, sourced answers instead of digging through files manually. It supports 7 different source types and runs across 4 separate deployment environments, built on Next.js for the frontend, FastAPI for the API layer, SurrealDB for storage, and Ollama for local model inference — keeping everything self-hosted rather than routing documents through a third-party API.

Beyond Q&A, it generates summaries and summary-slide PDFs automatically, which cut manual document-review time by roughly 25% for the team using it. It maintained approximately 99.5% uptime during internal testing.
